# The Electricity Question

Is AI bigger than the internet? On par with electricity? Rate it on instinct, then put in your own numbers and see whether the two agree.

A small, transparent model: a simple interactive version of Acemoglu's task-based framework (Hulten's theorem), extended with faster invention and risk, and mapped onto Nate Silver's Technological Richter Scale. Every assumption is a slider and every formula is written out on the page.

For a far more detailed model of AI and growth, see Epoch AI's GATE: https://epoch.ai/gate
